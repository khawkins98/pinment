Pinment

Pin comments to webpages you can access. Share the annotations as a single URL.

No backend. No accounts. The URL is the review.

Pinment is built for desktop browsers. Bookmarklets need a bookmarks bar, which isn't available on mobile. Visit this page on a laptop or desktop to get started.
  1. 1

    Add the bookmarklet

    Drag this button to your bookmarks bar:

    Pinment Drag to bookmarks bar
    Can't see your bookmarks bar?

    Show it with a keyboard shortcut:

    Chrome / EdgeCtrl+Shift+B
    FirefoxCtrl+Shift+B
    Mac (all browsers)Cmd+Shift+B

    Or: right-click the bookmarklet button above, choose Bookmark This Link, and save it to your bookmarks bar.

  2. 2

    Open the page to review

    Visit the published, staging or local page you want to review. Login is still required on private pages; strict CSP can block the bookmarklet.

  3. 3

    Drop pins & comment

    Click the bookmarklet and choose Start annotating on this page. Click a location, add your comment and name, then choose Save.

  4. 4

    Share the URL

    Choose Share & Export, then Copy. Recipients install Pinment, choose Open target page and Open page →, then activate Pinment on that page. Replies need a newly shared link.

What you get

Pin comments

Mark locations on the page and attach comments. Page and browser restrictions apply.

Share as URL

The link contains your comments and target URL. Anyone with the complete link can read that review data.

Element anchoring

Pins follow matching DOM elements. Changed elements can trigger saved pixel positions; check placement after layout changes.

Import & export JSON

Download JSON from Share & Export. On the reviewed page, activate Pinment and select Choose JSON file… to load a received file.

Drag to reposition

Placed a pin in the wrong spot? Drag it to the right location, no need to delete and re-create.

Thread replies

Reply to any pin to turn it into a conversation. Replies travel with the share URL.

Categories & status

Label pins as text, layout, missing, or question. Mark issues resolved when they're fixed.

Page restrictions

Strict CSP can block the bookmarklet loader. The optional extension injects a bundled script; browser-internal pages remain restricted.

Export as PDF

Export a screenshot/comment report. PDF libraries load from a CDN; network, CSP or cross-origin image restrictions can prevent export or omit content.

Preview an exported JSON file here to find its target URL. Import large reviews directly with Pinment on that page. Copy share URL does not create a link from an imported file.

Annotation review

Install the Pinment bookmarklet below, choose Open target page and Open page →, then activate Pinment on that page. If pins do not load, paste the original share URL into the welcome dialog and choose Load. Login is still required on private pages; check pin placement if the page has changed.
